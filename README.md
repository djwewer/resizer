# Resizer

Вертикальне відео (9:16) → **16:9**, **1:1** і **4:5** з розмитим, затемненим фоном з того ж відео.
Рендер робить нативний `ffmpeg` на вашому комп'ютері з апаратним енкодером (Apple VideoToolbox,
NVIDIA NVENC, Intel Quick Sync, AMD AMF, VAAPI). На macOS інтерфейс відкривається у власному вікні,
на Windows/Linux — у браузері на `localhost`.

## macOS — застосунок Resizer.app

1. Скачайте **Resizer.dmg** зі сторінки [Releases](https://github.com/djwewer/resizer/releases/latest).
2. Відкрийте його і перетягніть **Resizer** у папку **Applications**
   (якщо там уже є старий Resizer — натисніть «Замінити»).
3. Запустіть Resizer з «Програм», Launchpad або Spotlight.
   - Перший запуск: якщо немає ffmpeg — застосунок запропонує встановити його сам (відкриється Термінал, один раз).
   - Якщо macOS пише «неможливо перевірити розробника»: **Системні параметри → Конфіденційність і безпека → Все одно відкрити**
     (або в Терміналі: `xattr -dr com.apple.quarantine /Applications/Resizer.app`). Це потрібно лише один раз.
4. Відкриється вікно Resizer — перетягніть одне або кілька відео, вони стануть у **чергу**.
   Налаштуйте, натисніть **Рендерити все** — відео рендеряться по одному.

Без DMG: `git clone https://github.com/djwewer/resizer.git` (або **Code → Download ZIP**) і запустіть `Resizer.app` з папки.

- Готові файли: **~/Movies/Resizer** (кнопка «Відкрити папку» в інтерфейсі).
- Terminal не потрібен: сервер працює у фоні й зупиняється разом із вікном (якщо йде рендер — апка перепитає).
- Лог: `~/Library/Logs/Resizer.log`. Оновлення: скачати новий DMG і замінити Resizer у «Програмах».

### Для розробки (macOS)

- Вікно — Swift-застосунок, джерело в `macos/ResizerApp.swift`. Після змін у `Resizer.app` (у тому числі
  Python/веб-файлах) запустіть `macos/build.sh` — він перезбирає й перепідписує застосунок
  (потрібні Xcode Command Line Tools); зібраний бінарник комітиться в репозиторій.
- DMG: `macos/make-dmg.sh` → `dist/Resizer.dmg` (не комітиться, викладається в Releases).
  Фон вікна — `macos/dmg/background.html`, після змін: `macos/dmg/render-background.sh`.

## Windows / Linux

Потрібні **Python 3.9+** і **ffmpeg** (`winget install Gyan.FFmpeg` / `sudo apt install ffmpeg`).
Запуск: `start.bat` (Windows), `start.sh` (Linux) або `python3 resizer.py` (код лежить у `Resizer.app/Contents/Resources`). Готові файли — у папці `output/`.

## Запуск з терміналу (без інтерфейсу, пакетно)

```bash
python3 resizer.py video.mp4                     # 16:9 + 1:1, 5 Мбіт/с, 1080p
python3 resizer.py video.mp4 -f 16x9,1x1,4x5     # + 4:5 (1080×1350)
python3 resizer.py *.mov -b 8 -r 1440            # кілька файлів, 8 Мбіт/с, 1440p
python3 resizer.py clip.mp4 -n "Моя назва"                # → 16x9_Моя назва.mp4, 1x1_Моя назва.mp4
python3 resizer.py clip.mp4 -f 16x9 --blur 70 --dim 40 -o ~/Desktop/out
python3 resizer.py --list-encoders               # які енкодери працюють на цій машині
```

| Параметр          | За замовчуванням | Опис                                       |
|-------------------|------------------|--------------------------------------------|
| `-b, --bitrate`   | `5`              | бітрейт відео, Мбіт/с                      |
| `-r, --res`       | `1080`           | коротка сторона: 720 / 1080 / 1440 / 2160 (4:5 при 1080 → 1080×1350) |
| `-f, --formats`   | `16x9,1x1`       | які формати робити: `16x9`, `1x1`, `4x5`   |
| `--blur`          | `50`             | сила розмиття фону, 0–100                  |
| `--dim`           | `30`             | затемнення фону, %                         |
| `--codec`         | `h264`           | `h264` або `hevc`                          |
| `--encoder`       | `auto`           | конкретний енкодер ffmpeg, напр. `h264_nvenc` |
| `--no-hwdec`      | —                | вимкнути апаратне декодування              |
| `-n, --name`      | назва вхідного   | назва виходу (для одного файлу), формат іде префіксом |
| `-o, --out`       | `./output`       | папка для результатів                      |

## Чому швидко

- **Одне декодування на обидва формати.** Вхід декодується один раз, передній план масштабується один раз, обидва файли кодуються паралельно в одному процесі ffmpeg.
- **Блюр на крихітному кадрі.** Фон зменшується до 160 px, розмивається і лише потім збільшується — у ~100 разів дешевше за блюр повнорозмірного кадру, візуально однаково.
- **Апаратний енкодер** вибирається автоматично (реальною тестовою кодуванням, а не просто зі списку). Якщо GPU-енкодер падає — автоматичний відкат на CPU (x264 `veryfast`).
- **Аудіо копіюється** без перекодування (AAC/MP3/ALAC), `faststart` для миттєвого прев'ю.

Орієнтир на 10-хвилинне 1080×1920 відео: Mac на Apple Silicon (VideoToolbox) — приблизно 1–2 хв на обидва формати;
CPU-only на 4 ядрах — ~5 хв. Реальна швидкість залежить від машини — дивіться множник `×` під час рендеру.
