# Resizer: логотип, пекшот, формат 9:16, стрілка в DMG

Дата: 2026-11-13. Статус: погоджено.

## Логіка обробки одного креативу (9:16)

1. Пекшот (якщо увімкнено для цього відео) накладається поверх кінця оригіналу:
   закінчується разом із креативом (старт `T0 = max(0, тривалість креативу − тривалість пекшоту)`),
   перші 16 кадрів (за fps креативу) проявляється від прозорого до повного. Пекшот масштабується
   з обрізкою під розмір креативу і приводиться до його fps. Звук пекшоту ігнорується.
2. Результат іде у звичайний ресайз з блюром: 16:9, 1:1, 4:5 — і новий формат **9:16**
   (оригінальна пропорція, `9x16_<назва>.mp4`, 1080 → 1080×1920).
3. На кожен вихідний формат накладається логотип у своїй позиції/розмірі. Якщо є пекшот, лого
   гасне за ті самі 16 кадрів, коли пекшот проявляється (пекшот «вище всіх»). Без пекшоту — до кінця.
4. Усе в одному процесі ffmpeg, як зараз: одне декодування, всі формати кодуються паралельно, черга по одному.

## Інтерфейс

- Формати: 9:16 · 4:5 · 1:1 · 16:9. Новим користувачам увімкнені всі.
- Блок «Логотип»: перемикач «Додати лого», мініатюра, «Замінити» (PNG), «Стандартний» (повернути вбудований).
  Вбудований логотип — `Contents/Resources/assets/logo.png` (MyMuse_LOGO.png).
- Блок «Пекшот»: один відеофайл (MP4/MOV), назва + тривалість, ✕ — прибрати.
- Рядок черги: галочка «Пекшот» (за замовчуванням увімкнена; видно, лише коли пекшот вибрано).
- Прев'ю: 4 канваси. На кожному лого перетягується мишкою, розмір — за правий нижній кут.
  Позиція зберігається окремо для кожного формату як частки кадру `{x, y, w}` (лівий верхній кут,
  ширина відносно ширини кадру). Біля кінця відео в прев'ю видно проявлення пекшоту.

## Збереження

- Папка даних: `--data` (Resizer.app → `~/Library/Application Support/Resizer`, інакше `./data`).
- Там: свій логотип, пекшот, `prefs.json` (позиції лого, назва пекшоту). Все пам'ятається між запусками.
- Позиції/шляхи фіксуються в задачі в момент «Рендерити все».

## API

- `GET /api/assets` — лого (url, розміри, свій/вбудований), пекшот (url, назва, info), позиції.
- `POST /api/assets/logo` (тіло — файл), `POST /api/assets/logo/reset`.
- `POST /api/assets/packshot` (тіло — файл), `POST /api/assets/packshot/delete`.
- `POST /api/logo-pos` — `{fmt: {x, y, w}}`.
- `POST /api/render` — додатково `logo: bool`, `packshot: bool`.

## DMG

Пунктирну стрілку між іконками замінити на велику суцільну; перерендерити фон, перезібрати DMG.
Версія застосунку 1.3 (на GitHub уже є релізи 1.1 і 1.2).
