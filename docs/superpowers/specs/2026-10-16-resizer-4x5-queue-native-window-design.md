# Resizer: 4:5, черга відео, нативне вікно macOS

Дата: 2026-10-16. Статус: погоджено.

## 1. Формат 4:5

- Новий формат `4x5`, вихід `4x5_<назва>.mp4`.
- Вибрана роздільність — коротка сторона кадру: для горизонтальних і квадратних форматів це висота
  (16:9 → 1920×1080, 1:1 → 1080×1080), для вертикальних — ширина (4:5 → 1080×1350, 4K → 2160×2700).
- Фільтр ffmpeg: передній план масштабується один раз на кожну різну висоту виходу
  (16:9 і 1:1 — спільний, 4:5 — окремий). Шлях «передній план на всю висоту» використовується лише
  коли він вміщується в усі вибрані формати; інакше — вписування в кожен формат окремо.
- UI: третій перемикач і третій канвас прев'ю. Новим користувачам 4:5 увімкнено за замовчуванням,
  збережені налаштування не змінюються. CLI: `-f 16x9,1x1,4x5`.

## 2. Черга

- Drop-зона і вибір файлу приймають кілька файлів; завантаження на сервер — по одному.
- Список «Черга»: назва (редагується до старту), теги відео, статус, прогрес, ✕ (видалити/скасувати),
  ↻ (повторити для готових/скасованих/з помилкою).
- Налаштування спільні; фіксуються в момент «Рендерити все (N)». N — завантажені відео без активного
  чи завершеного рендеру. Під час рендеру можна додати ще і знову натиснути кнопку.
- Клік по рядку — прев'ю цього відео, а для готового — його результати.
- Бічна панель: загальний прогрес партії («2 з 5»), швидкість, час до кінця черги, «Скасувати все».
- Сервер: один потік-виконавець і `queue.Queue` замість потоку на кожен рендер.
  Нові ендпоінти: `GET /api/jobs`, `POST /api/cancel-all` (чекає, доки ffmpeg зупиниться і
  незавершені файли видаляться), `POST /api/uploads/<id>/delete`, `POST /api/reveal`.

## 3. Нативне вікно (macOS)

- `Contents/MacOS/Resizer` — Swift-застосунок (AppKit + WKWebView), джерело в `macos/ResizerApp.swift`,
  збірка `macos/build.sh` (універсальний arm64 + x86_64, macOS 10.15+). Бінарник комітиться.
- Перевірки Python/ffmpeg і старт сервера — колишній bash-лаунчер, перенесений у
  `Contents/Resources/launch.sh`; друкує `URL PID` або завершується з кодом 1 (діалоги показує сам).
- Вікно: перетягування файлів, NSOpenPanel із множинним вибором, меню Edit (Cmd+C/V), Cmd+W/Cmd+Q.
- Закриття вікна = вихід. Якщо черга активна — підтвердження, потім `cancel-all` і SIGTERM серверу.
  Сервер обробляє SIGTERM як Ctrl+C. `--idle-exit 300` лишається страховкою.
- Сторінка знає, що вона у вікні (`window.RESIZER_NATIVE`): «Завантажити» замінюється на
  «Показати у Finder»; стан черги передається у Swift через `messageHandlers.busy`.
- Якщо WebKit не підтримує `ctx.filter`, прев'ю розмиває фон вручну (як ffmpeg: зменшення до 160 px,
  box blur, збільшення).
- Windows/Linux без змін — браузер.

## Перевірка

- Рендер тестового вертикального відео у 3 формати, розміри через ffprobe.
- Черга з 3 відео: послідовно; скасування одного не зупиняє інших; `cancel-all` видаляє незавершені файли.
- Вікно: відкривається, сервер зупиняється після закриття.
